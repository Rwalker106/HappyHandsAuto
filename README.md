# HappyHands Autospa

HappyHands Autospa is a premium car detailing web application built with Node.js and Express. It serves as a modern, high-converting, and visually appealing landing page for a car detailing business, featuring responsive design, glassmorphism UI elements, and a clean interface.

## Project Structure

- `index.js`: The main Express server file which serves the static assets.
- `public/`: The directory containing the front-end assets (HTML, CSS, JS, Images).
- `package.json`: Contains project metadata and dependencies.

## Features

- **Responsive Design**: Looks great on both desktop and mobile devices.
- **Modern UI**: Uses advanced CSS styling, custom Google fonts, and elegant hover animations.
- **Express Server**: Lightweight Node.js server to serve the website.

## Getting Started

### Prerequisites

- Node.js (v14 or higher recommended)
- npm (Node Package Manager)

### Installation

1. Clone or download this repository.
2. Install the required dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the server, run:
```bash
node index.js
```

The server will start running on port `3000` (or `process.env.PORT` if set). Open your browser and navigate to:
```
http://localhost:3000
```

## Technologies Used

- **Font-End**: HTML5, Vanilla CSS, JavaScript
- **Back-End**: Node.js, Express.js
- **Fonts**: Google Fonts (Inter)
